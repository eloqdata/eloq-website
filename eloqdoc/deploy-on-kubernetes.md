# Deploy EloqDoc on Kubernetes

## Overview

EloqDoc can be deployed on Kubernetes using the **Eloq Operator**, which provides a cloud-native approach to managing EloqDoc clusters. The operator automates deployment, scaling, and management tasks, making it easier to run EloqDoc in production Kubernetes environments.

## Supported Platforms

The Eloq Operator supports deployment on:

- **AWS EKS** (Elastic Kubernetes Service)
- **Baidu Cloud CCE** (Cloud Container Engine)
