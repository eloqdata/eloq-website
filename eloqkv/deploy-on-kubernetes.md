# Deploy EloqKV on Kubernetes

## Overview

EloqKV can be deployed on Kubernetes using the **Eloq Operator**, which provides a cloud-native approach to managing EloqKV clusters. The operator automates deployment, scaling, and management tasks, making it easier to run EloqKV in production Kubernetes environments.

## Supported Platforms

The Eloq Operator supports deployment on:

- **AWS EKS** (Elastic Kubernetes Service)
- **Baidu Cloud CCE** (Cloud Container Engine)
