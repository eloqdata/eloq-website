# EloqKV 与其他键值存储的区别

## 事务支持

EloqKV 支持完整的 ACID 事务,包括:

- 原子性(Atomicity): 事务中的所有操作要么全部成功,要么全部失败。
- 一致性(Consistency): 事务执行前后数据库保持一致状态。
- 隔离性(Isolation): 并发执行的事务之间互不干扰。
- 持久性(Durability): 一旦事务提交,其修改将永久保存。

这使得 EloqKV 不仅可以用作缓存,还可以作为主数据库使用。

## 分布式一致性

EloqKV 使用 Raft 共识算法来保证分布式一致性。这意味着:

- 所有节点对数据顺序达成一致
- 即使在网络分区的情况下也能保持一致性
- 支持自动故障转移和领导者选举

## 存储引擎选择

EloqKV 支持多种存储引擎:

1. RocksDB (嵌入式)

   - 适用于单机部署
   - 提供快速的本地存储
   - 支持数据压缩

2. Cassandra (分布式)

   - 适用于大规模分布式部署
   - 提供跨区域复制
   - 支持线性扩展

3. DynamoDB (云原生)
   - 适用于云环境部署
   - 按需付费
   - 自动扩缩容

## 性能优化

EloqKV 采用了多项性能优化技术:

- 多线程并发处理
- 异步日志写入
- 智能缓存管理
- 批量操作支持

## 监控和管理

EloqKV 提供完整的监控和管理功能:

- Prometheus 指标收集
- Grafana 仪表板
- 命令行管理工具
- REST API 接口

## 兼容性

- 完全兼容 Redis 协议
- 支持大多数 Redis 命令
- 可以直接使用 Redis 客户端
- 支持 Redis 集群协议
