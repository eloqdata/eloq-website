# Install EloqKV from Binary

## Download and unzip EloqKV tarball

EloqKV is compatible with RHEl 7, RHEL 8, Ubuntu 18.04, Ubuntu 20.04, Ubuntu 22.04 and Ubuntu 24.04. Please contact us to acquire the latest EloqKV tarball.

## Prepare EloqKV config file

EloqKV uses a configuration file `conf/eloqkv.ini` to customize settings. Below is an example of how to configure EloqKV to run on a local machine.

Note: set `ip` field to 127.0.0.1 will block external access to EloqKV. It is recommened to set `ip` to either a private or public IP address.

```yaml
[local]
# It is recommended to set the IP to either a private or public IP address
ip=127.0.0.1
port=6379
# It is recommended to set core_number to approximately 70% of the total available cores for optimal performance.
core_number=3
# Checkpoint_interval determine the frequency of flushing dirty records into data store
checkpoint_interval=60
# Set node_memory_limit_mb to 60% of the total system memory to optimize resource allocation.
node_memory_limit_mb=8192
# Whether enable data store
enable_data_store=none
# Whether enable redo log
enable_wal=none
path=data
# It is recommended to set event_dispatcher_num to one-seventh of core_number for balanced performance.
event_dispatcher_num=1

[cluster]
# ip_port_list should include all eloqkv nodes. For a single node deployment, set it to match the ip:port specified in the [local] section.
ip_port_list=127.0.0.1:6379

[store]
# data store related configuration. Keep it empty for rocksdb based data store.
```

### Start EloqKV server

The EloqKV `eloqkv` executable binary is installed in the `EloqKV/bin` directory. Start the server on the local machine using the commands below.

```shell
cd ${HOME}/EloqKV
./bin/eloqkv --config=conf/eloqkv.ini > log 2>&1 &
```

### Connect to EloqKV server

EloqKV is compatible with Redis protocol. Use any redis client to connect to EloqKV. Please use the same ip and port in config file `eloqkv.ini`

```shell
redis-cli -h 127.0.0.1 -p 6379
```

## Explore More Features

### Enable Data Store Feature

EloqKV supports the integration with pluggable data stores, enabling data persistence even when the EloqKV service is stopped. This capability facilitates the implementation of tiered storage strategies, allowing hot data to reside in memory for quick access, while cold data can be offloaded to more persistent storage solutions.

Edit `eloqkv.ini` and restart database to enable data store of EloqKV.

```shell
[local]
enable_data_store=all
```

Note that enable persisitent kv will consume CPU resource to flush records in memory to kv store periodically. As a result, reduce core_num in `eloqkv.ini` when enable persisitent kv.

### Enable Transaction Feature

Upon enabling the Write-Ahead Logging (WAL) and integrating a data store, EloqKV evolves into a fully transactional key-value store. The WAL ensures atomicity in distributed transactions and maintains data integrity by preventing data loss in the event of a system crash.

Edit `eloqkv.ini` and restart database to enable WAL of EloqKV.

```shell
[local]
enable_wal=all
```
