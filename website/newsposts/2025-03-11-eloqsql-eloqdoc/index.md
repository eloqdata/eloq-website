我们很高兴向您介绍 **EloqSQL** 和 **EloqDoc**，这是我们数据库产品组合中两个具有突破性的新成员。

<!--truncate-->

**EloqSQL** 是一个兼容 MySQL 的完全分布式关系型数据库，而 **EloqDoc** 是一个兼容 MongoDB 的分布式 JSON 文档数据库。两者都基于我们革命性的模块化[数据基层](/blog/2024/08/11/data-substrate)技术构建，继承了这一前沿架构的所有优势，包括各种规模下的最佳性能，以及具有可选隔离级别的完整分布式 ACID 事务能力，以确保数据的完整性和可靠性。

[**EloqSQL**](/product/eloqsql)是一个兼容 MySQL 的分布式关系型数据库，为高性能、可扩展性、兼容性和弹性设立了新标准。它专为现代应用程序设计，支持多写入者、二级索引、跨可用区数据复制和热备份，以实现不间断运行。**EloqSQL** 经过精心设计，能够轻松处理最苛刻的工作负载，通过业界最广泛接受的 API 彻底改变了您管理和处理数据的方式。

[**EloqDoc**](/product/eloqdoc)是一个兼容 MongoDB 的分布式 JSON 文档数据库，能够利用分层云存储实现无与伦比的灵活性和效率。凭借快速和动态的容量扩展，EloqDoc 可以无缝适应不断变化的需求，始终确保最佳性能。在许多场景下，它比 MongoDB 提供更好的性能，同时保持 API 兼容性和无痛迁移路径。EloqDoc 前所未有的分布式事务能力消除了传统 NoSQL 和 SQL 数据库之间的主要区别之一，将 NoSQL 技术的优势与云存储的强大功能相结合，带来卓越的数据管理体验。

**EloqSQL** 和 **EloqDoc** 现已开放预览版本，您可以从我们的[网站](https://www.eloqdata.com)下载。您可以按照我们的文档学习如何设置单节点测试服务器或集群。

**EloqSQL** 和 **EloqDoc** 共同代表了数据库技术的重大进步，为各种应用场景提供了强大、可扩展和高性能的解决方案。我们诚邀您探索这些新工具，与我们一起体验数据管理的未来。敬请关注更多更新和深入分析，了解这些产品如何简化您的数据基础设施并降低数据库成本。

展望未来，我们对 Eloq 数据库家族的持续扩展充满期待。**数据基层**架构为我们提供了无与伦比的灵活性和敏捷性，使我们能够快速开发高质量、具有竞争力的产品，以满足现代 AI 驱动应用程序不断发展的数据需求。
