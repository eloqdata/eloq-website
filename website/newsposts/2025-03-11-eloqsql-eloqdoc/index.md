We are thrilled to introduce **EloqSQL** and **EloqDoc**, two groundbreaking additions to our database portfolio.

<!--truncate-->

**EloqSQL** is a MySQL-compatible, fully distributed relational database, while **EloqDoc** is a MongoDB-compatible, distributed JSON document database. Both are built on our modular [Data Substrate](/blog/2025/07/14/technology) technology, inheriting all the benefits of this cutting-edge architecture, including best-in-class performance in all scales and full distributed ACID transactional capabilities with selectable isolation levels to ensure data integrity and reliability.

[**EloqSQL**](/product/eloqsql) is a MySQL-compatible distributed relation database that sets a new standard for high performance, scalability, compatibility, and resilience. Designed for modern applications, it supports multiple writers, secondary indexes, cross-AZ data replication, and hot-backup for non-stop operation. Engineered to handle the most demanding workloads with ease, **EloqSQL** transforms the way you manage and process data with the most widely accepted API in the industry.

[**EloqDoc**](/product/eloqdoc) is a MongoDB-compatible distributed JSON document database that can leverage tiered cloud storage for unparalleled flexibility and efficiency. With fast and dynamic capacity scaling, EloqDoc adapts seamlessly to changing demands, ensuring optimal performance at all times. It delivers significantly better performance than MongoDB in many scenarios while maintaining API compatibility and a painless migration path. EloqDoc’s unprecedented distributed transaction capability eliminates one of the major distinctions between traditional NoSQL and SQL databases, combining the best of NoSQL technology with the power of cloud storage for an exceptional data management experience.

Both **EloqSQL** and **EloqDoc** are immediately available for preview and can be downloaded from our [website](https://www.eloqdata.com). You can learn about how to set up a single node test server or a cluster following our documents.

Together, **EloqSQL** and **EloqDoc** represent a significant leap forward in database technology, providing robust, scalable, and high-performance solutions for a wide range of applications. We invite you to explore these new tools and experience the future of data management with us. Stay tuned for more updates and in-depth insights into how these products can simplify your data infrastructure and reduce your database costs.

Looking ahead, we are excited about the continued expansion of the Eloq family of databases. The **Data Substrate** architecture gives us unparalleled flexibility and agility to rapidly develop high-quality, competitive products that meet the evolving data needs of modern AI-driven applications.
