We are thrilled to announce that **EloqData** is open-sourcing our core products: **EloqKV**, **EloqSQL**, and **EloqDoc**. This marks a significant milestone in our journey to build a more open and collaborative database ecosystem.

<!--truncate-->

## Our Open Source Journey

Today, we're taking a major step by making our database solutions available to the open-source community. We believe that innovation thrives through collaboration, and we're excited to work with developers worldwide to build better database solutions.

## What's Being Open Sourced?

### EloqKV

A high-performance distributed transactional database with Redis API compatibility. EloqKV offers:

- Full ACID transaction support
- Horizontal scalability
- Redis API compatibility
- Multi-model support

### EloqSQL

A MySQL-compatible distributed SQL database that provides:

- Distributed SQL processing
- MySQL wire protocol compatibility
- Strong consistency
- Horizontal scalability

### EloqDoc

A MongoDB-compatible document store featuring:

- Document-oriented storage
- MongoDB query language support
- Distributed architecture
- Flexible schema design
