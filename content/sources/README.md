# Selected evidence

Briefs select public repository documentation or a text/Markdown excerpt saved here, paired with its exact public HTTPS citation URL. Sources are sent to the configured OpenAI model only when generation runs. Never place confidential information, credentials, customer data, or unpublished roadmap material in the selected files.

To cite an external benchmark, compatibility page, or announcement, verify its current primary source, save a concise excerpt here, and include the source title, URL, access date, relevant conditions, and limitations. The tool deliberately does not crawl URLs: a URL alone is not evidence. Source manifests record file hashes; changing a source invalidates the draft and requires a new draft id.

For reproducibility, retain the exact excerpt used during review. Do not copy full copyrighted articles. The claim ledger should quote only the small portion needed to check a claim. A dated first-party claim is historical evidence, not proof that a product or price is unchanged today.
